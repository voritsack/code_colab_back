Withdraw

Stops offering updates and deletes the stored build. Copies already installed keep working exactly as they are.

From the command line

Same result, if you would rather commit the build:

python scripts/publish_extension.py path/to.vsix --notes "…"

The deployment folder is rebuilt from git on every start, so a build uploaded here disappears on the next redeploy unless it is committed as well.
